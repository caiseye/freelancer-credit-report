## 무엇을 볼 수 있나요

심사 결과가 갈리는 **5가지 케이스**를 **앱 / 웹** 두 가지 화면으로 확인합니다.
첫 화면에서 케이스와 화면 종류를 고르면 그 조건으로 전체 흐름이 실행됩니다.

| 케이스 | 판정 | 특징 |
|---|---|---|
| 정상 승인 | 양호 | 51개월 무중단 · 이상거래 없음 · DSR 4.4% · 월 46만원 흑자 |
| 이상거래 감지 | 제출 보류 | 고액 현금인출·순환거래·가장입금 위험 3건 → 제출 차단 |
| 소득 하락 | 주의 | 12개월간 소득 −66% · 예측도 우하향 · 한도 대폭 축소 |
| 이력 부족 | 정보 부족 | 개업 8개월 · 일부 지표 산출 불가 · 예측 구간 ±30% |
| 부채 과다 | 한도 없음 | DSR 72.4% · 원리금이 가처분소득의 110% · 추가 한도 0원 |

### 리포트 구성

1. 심사 요약 — 종합 판정과 핵심 지표
2. 소득 분석 — 실적·예측 구간(P10/P50/P90)·수입원 집중도(HHI)
3. 계속근무가능성 — 동종 대비 상대평가와 항목별 배점
4. 근로 성실도 — 6개 축 가중평균 (표본 부족 축은 재정규화)
5. **타행 여신 현황** — 기관별 대출·한도·금리·연체, 신용평점, 카드 한도소진율
6. **소비패턴 · 가처분소득** — 카테고리별 소비, 결제수단, 가처분소득 산출 폭포
7. 이상거래 검사 — 12개 규칙 판정과 사유
8. 상환여력 (DSR) — 원리금 근거와 규제 상한 대비
9. 자료 출처 — 수집 기관과 조회 결과
10. 진본 확인 — 문서 메타·해시·타임스탬프

### 앱과 웹의 차이

- **앱** — 모바일 카드 스택. 근거는 바텀시트로 접어둠
- **웹** — 목차 + 번호 매긴 절 + 표 중심의 문서형. 근거를 전부 펼침

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

주소에 상태가 남습니다. `#/<케이스>/<app|web>/<단계>` 형식이라
`#/fds_alert/web/5` 처럼 직접 열거나 링크로 공유할 수 있습니다.

## 검증

데이터 정합성과 화면 분기를 렌더 단계에서 확인합니다.

```bash
npx esbuild smoke.jsx  --bundle --platform=node --format=cjs --outfile=smoke.built.cjs  --loader:.jsx=jsx
node -e "require('./smoke-setup.cjs'); require('./smoke.built.cjs');"   # 5케이스 × 2모드 × 8화면

npx esbuild assert.jsx --bundle --platform=node --format=cjs --outfile=assert.built.cjs --loader:.jsx=jsx
node -e "require('./smoke-setup.cjs'); require('./assert.built.cjs');"  # 케이스별 분기가 실제로 화면에 반영되는지
```

## 배포

```bash
npm run deploy     # 빌드 후 gh-pages 브랜치로 올립니다
```

### 자동 배포로 전환하려면

지금은 수동 배포입니다. `.github/workflows/` 를 push하려면 토큰에 `workflow`
스코프가 필요한데, 그 권한 없이도 배포되도록 `gh-pages` 브랜치 방식을 썼습니다.
push할 때마다 자동 배포되게 하려면:

```bash
gh auth refresh -s workflow
```

인증 후 Actions 워크플로를 추가하고, 저장소 설정에서 Pages 소스를
`GitHub Actions` 로 바꾸면 됩니다.

## 구조

```
src/
  core.js        팔레트 · 숫자 포맷 · 훅
  scenarios.js   5개 케이스 정의 + 파생값 계산(합계·변동계수·HHI·DSR·가처분소득)
  finance.js     타행 여신 · 카드 소비 원천 데이터
  ui.jsx         앱/웹 모드를 아는 UI 프리미티브
  blocks.jsx     앱·웹이 함께 쓰는 분석 블록(가처분소득 폭포·여신표·소비차트)
  screens.jsx    가입 흐름과 모바일 리포트 카드
  webreport.jsx  웹 전용 문서형 리포트
  App.jsx        케이스 선택 화면 · 해시 라우터 · 테스트 바
```

수치는 **계산으로 파생**됩니다. 소득 배열만 바꾸면 변동계수·예측 구간·DSR·
가처분소득이 함께 움직이고, 계속근무가능성 총점은 항목 배점의 합으로만 만들어집니다.
그래서 카드에 보이는 숫자와 상세 근거가 갈라지지 않습니다.
